# IA & Machine Learning: Atividade de Laboratório (Clustering com K-Means)

## Contexto da Aula

Este notebook foi desenvolvido como parte das aulas práticas de Inteligência Artificial e Machine Learning. O material aborda conceitos fundamentais de **aprendizado não supervisionado**, explorando o algoritmo de *clustering* **K-Means** para agrupar países a partir de indicadores socioeconômicos e de saúde do dataset *Country Data*.

## Atividade Desenvolvida (LAB)

A atividade proposta sob a diretriz **"IA ML Cluster - IA não supervisionada"** consistiu em um mini projeto prático, com dados escolhidos no Kaggle (diferentes para cada equipe), para experimentar e explorar um modelo de *clustering*.

### Detalhes do Projeto:

- **Equipe:** Atividade realizada em dupla - João Avila e Kauã Cavalheiro.
- **Dataset Escolhido:** *Unsupervised Learning on Country Data* (obtido no [Kaggle](https://www.kaggle.com/datasets/rohan0301/unsupervised-learning-on-country-data)), com indicadores de 167 países.
- **Técnica Abordada:** Implementação do **K-Means** para agrupar países com perfis de desenvolvimento parecidos.
- **Objetivo:** Realizar a análise exploratória, tratar a assimetria das variáveis (transformação logarítmica), padronizar os dados, escolher o número de grupos pelo método do cotovelo e pelo silhouette, avaliar os clusters com métricas internas (Silhouette, Davies-Bouldin e Calinski-Harabasz), visualizar os grupos com PCA, interpretar o perfil de cada grupo e identificar os países que mais precisam de ajuda humanitária.
